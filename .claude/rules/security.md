# 보안 컨벤션
- 모든 툴 호출은 화이트리스트 스코프를 벗어나면 실패해야 함
- 인젝션 테스트 케이스 추가 시 방어 전/후 결과를 반드시 함께 기록
- **외부 LLM 벤더 호출 금지 (ADR-021).** LLM 호출의 목적지는 `.env`의 `VLLM_BASE`
  하나뿐이다. 예외는 승인 게이트 6항목 중 **1번(대상 엔드포인트가 `VLLM_BASE`인가)을
  먼저** 묻고 사용자 승인을 받은 뒤에만 가능하다. 비용 규칙이 아니라 데이터 규칙이므로
  금액이 작아도 해소되지 않는다. 상세는 `.claude/rules/external-llm.md`.
