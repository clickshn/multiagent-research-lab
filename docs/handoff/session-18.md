### ⚠️ 결정 대기 ④ — 자연 변동 0이 ADR-025 판정 규칙에 주는 영향

ADR-025 판정 규칙은 "자연 변동을 넘는 하락 = 해악"이다. 자연 변동이 **0**이므로 S0c에서
**선택률이 1건만 줄어도(15/17 → 14/17, −5.9%p) 규칙상 해악**이고, pass/fail이 1건만 뒤집혀도 해악이다.
규칙은 사전 등록대로 두었고 **바꾸지 않았다.** S0c 전에 결정할 것:
(a) 그대로 적용 / (b) 최소 차이 하한(예: 2건)을 **S0c 측정 전에** Amendment로 추가 / (c) S0c에서도 2회 돌려
after 쪽 변동도 본다. 또 **분모(eligible)는 S0c에서 달라질 수 있다** — 재시도 여부가 1회차 선택에 달려 있어
재시도 호출 수가 변하기 때문이다. 비율과 함께 분자·분모를 병기해야 한다.

## 5. 확인 항목 (이번 측정에서 바꾸지 않은 것)

- **`LITELLM_LOCAL_MODEL_COST_MAP` 미설정.** litellm은 임포트 시 모델 가격표를 원격에서 받아올 수 있다.
  LLM 벤더 호출은 아니고 **이번 변경으로 새로 생긴 동작도 아니다**(파이프라인이 원래 호출 시점에 임포트했다 —
  워밍업은 시점만 앞당겼다). 데이터 유출 경로인지·끄는 게 맞는지 확인 필요. **이번 측정에서는 바꾸지 않았다(지시).**
- governance "측정 방법론"은 `LLM_CACHE` 환경변수 확인을 적는데 bench는 환경변수를 무시하고 `--cache`만 본다
  (session-17 §1, 서술 불일치·무해). 그대로 둠.
- 호출로만 확인 가능한 것 중 **자연 변동 폭만 측정했다.** `seed` 존중 여부, tool calling 서버 옵션(§5.4),
  동시 요청 수용(§5.3)은 이번 범위 밖 — 미확인.
