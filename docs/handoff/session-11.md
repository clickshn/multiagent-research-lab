## 1. 무슨 일이 있었나 — 한 문단

Session 0.5a에서 계약 검증용 추출을 **외부 Anthropic API(`claude-opus-5`)로 실행했다.**
이 프로젝트의 전제는 외부 LLM 벤더 비의존이다. 승인 게이트는 **목적·모델명·건수·
예상 비용**을 물었고 **전부 정확히 답변됐고 승인도 받았다.** 그런데 **"대상 엔드포인트가
`VLLM_BASE`인가"는 아무도 묻지 않았다.**

> **게이트가 있었고 통과했는데, 게이트가 확인해야 할 것을 확인하지 않았다.**
> 양식이 묻는 것은 전부 비용의 크기였다. **비용 게이트가 규칙 자리에 놓인 채 정상
> 작동했고, 그래서 실패 신호가 하나도 나지 않았다.**

숫자는 숨기지 않는다. 전문은 **ADR-021**.

| 항목 | 값 |
|---|---|
| 본문이 벤더로 나간 기사 | **49건** — 추출 30건(`claude-opus-5`) + 게이트 판정 19건(`claude-haiku-4-5`) |
| 함께 나간 것 | 시스템 프롬프트 v4 + structured output 스키마 (추출 입력의 대부분, 건당 약 9,200토큰) |
| 사내·고객 데이터 | **0건** — 단, **ADR-004(공개 자료 한정)가 막아 준 것**이고 전제 규칙이 작동한 결과가 아니다 |
| 비용 | **약 $2.13** (보존 30건 $2.058 + 스킵 19건 추정 $0.067) |
| 2단계 220건(약 $16) | **미실행** |

**이것은 플레이북 8장의 같은 패턴 다섯 번째 사례다.** 앞 네 건은 `docs/INTERVIEW_NOTES.md`
§4에 있고, 이번 것이 §4-(5)로 들어갔다. 앞 네 건과 종류가 한 겹 안쪽이다 —
장치가 고장 난 것이 아니라 **처음부터 다른 것을 재고 있었다.**

## 2. 무엇을 고쳤나

### 2.1 게이트 양식 — 1번이 엔드포인트다

`docs/governance.md` "승인 게이트"에 **6항목 양식**을 넣었다. 1번이 **"대상 엔드포인트가
`VLLM_BASE`인가"**이고, **아니오는 승인 대상이 아니라 규칙 위반**이다.
**모델명(4번)으로 1번을 대신하지 않는다** — 같은 모델 이름이 양쪽에 있을 수 있고,
판정 기준은 이름이 아니라 목적지다.

세 곳에 적었다. **ADR에만 있으면 다음 세션이 읽지 않는다.**

| 파일 | 역할 |
|---|---|
| `docs/governance.md` | 양식 전문. `CLAUDE.md` import로 **매 세션 자동 로드**된다 |
| `.claude/rules/external-llm.md` | 경로별 규칙(신규). 집행 장치와 **막지 못하는 것** |
| `.claude/rules/security.md` | 한 줄 규칙 + 포인터. `paths`에 `src/providers/**` 추가 |

### 2.2 집행 — 설득이 아니라 장치로

| 계층 | 파일 | 막는 것 |
|---|---|---|
| 도구 | `.claude/hooks/check-external-llm.sh` | Bash·PowerShell **명령 문자열**의 벤더 호스트 / SDK 임포트 / API 키 주입 / 외부 모델 CLI / 생산자 파이프라인 실행. exit 2 |
| 코드 | `src/providers/egress.py` + `ProviderSettings.__post_init__` | `VLLM_BASE`를 벤더로 바꿔 목적지를 돌리는 경로. **객체 생성 시점**에 실패 |

- 예외는 `.claude/external-llm-approved`(1회용, `.gitignore`)로만 열린다.
- `permissions.deny`를 쓰지 않았다 — **승인 파일로도 안 풀리므로**(session-07 실증)
  "승인 없이는 금지"라는 이 규칙의 상태를 잘못 표현한다. 근거는 ADR-021 Alternatives (나).
- 훅은 **파서가 없으면 통과가 아니라 차단**이다(fail-closed). `check-deploy-approval.sh`와 같다.
- 훅의 파서 탐색 순서를 `python → python3`으로 뒀다. 이 머신의 `python3`은 pyenv-win
  shim이라 호출당 약 1.9s인데 `python`은 약 0.2s다. **훅은 모든 Bash 호출마다 돈다.**
  또 `command -v`로 있는지만 보지 않고 **실제로 도는지**까지 본다 — shim은 PATH에
  잡히지만 bash에서 실행되지 않는다(실제로 여기서 한 번 막혔다).

- **오탐 대조를 함께 돈다.** 차단 케이스만 있는 검사는 "전부 차단"인 고장 난 게이트도

- ⚠️ 이 테스트는 **약 60초 걸린다.** 훅 프로세스를 케이스마다 실제로 띄우기 때문이고,

## 3. 🚩 뚫어 봤다 — 막은 것과 못 막은 것

**만든 것과 작동하는 것은 다르다.** 세션 안에서 실제로 시도했다.

| 시도 | 결과 |
|---|---|
| Bash 도구로 벤더 호스트가 든 명령 | **차단(exit 2)** |
| **PowerShell 도구**로 같은 시도 (session-07의 우회 경로) | **차단(exit 2)** |
| `VLLM_BASE`를 벤더로 교체 후 설정 로딩 | **차단** (`ExternalEndpointError`) |
| jq·python을 모두 감춘 환경 | **차단** (fail-closed) |
| 승인 파일이 있을 때 / 지운 뒤 | 통과 → 다시 차단 |
| **스크립트 파일 안에 벤더 호출을 숨기고 `python <파일>`** | ⚠️ **통과했다 — 막지 못한다** |

또한 `settings.json` 변경이 **재시작 없이 이번 세션에서 바로 유효**했다.

### ⚠️ 막지 못하는 것 — 기억이 아니라 테스트에 적혀 있다

케이스 파일에 **기대값 0(통과)** 으로 5건 고정했다. 인젝션 테스트에서 탐지 우회 3종을
고의로 통과시켜 한계를 고정한 것과 같은 방식이다.

- **스크립트 파일 / 셸 스크립트 / Makefile 경유** — 명령줄에 벤더 흔적이 없다
- **난독화**(base64 등) — 문자열 검사를 통과한다
- **에이전트 자신의 모델 호출과 Agent/Task 서브에이전트** — 훅의 적용 범위 밖
- **MCP 도구 경유 네트워크 호출** — 매처가 `Bash|PowerShell`이다
- **거부 목록의 빈칸** — 새 벤더·사설 프록시는 목록에 없다

> 이 목록은 결함 고백이 아니라 **적용 범위**다. 범위 밖에서 도는 코드가 바로
> 생산자 레포이고, 그래서 §6이 있다.

### ⚠️ 자기참조 — 이번에도 걸렸다

훅은 명령 문자열을 검사하므로 **벤더 호스트를 예시로 적는 명령은 그 자체가 차단된다.**
ADR·규칙 문서를 **Write 도구로 썼다.** 회피가 아니라 정상 경로다(세션 7과 같은 문제,
같은 해법). 커밋 메시지에도 트리거 문자열을 넣지 않는다.

## 5. 📌 다음 세션 과제 — 추출 단계를 KT Cloud vLLM으로 이전

**목적은 비용 절감이 아니라 전제 위반 해소다.** ADR-002가 서빙을 vLLM(`gemma-4-31B-it`)로
정했는데 **코퍼스 생성만 외부 벤더를 쓰고 있다.**

- **대조 설계:** 이미 Opus 5로 뽑은 **30건과 동일한 입력**을 vLLM으로 다시 돌린다.
  생산자 보존소에 원문이 남아 있어 수집을 다시 하지 않으므로 **추가 비용 0**이고,
  "같은 입력 · 다른 모델"의 단일 변수 비교가 된다.
- **판정 기준은 데이터를 보기 전에 등록했다** →
  **`docs/eval/preregistration-extraction-on-vllm.md`** (이번 세션 커밋).
  요약: **① 통제어휘 이탈률 ≤ 5% 그리고 ② structured output 실패율 ≤ 10%** 이면 합격.
  ③ judge 점수 차이(≤ 0.5)는 기록하되 단독으로 불합격을 만들지 않는다.
- ⚠️ **judge도 vLLM으로 바꿔야 한다.** 생산자 `config.yaml`의 `eval.judge_model`이
  `claude-opus-5`다 — **판정하는 행위 자체가 같은 위반이 된다.**
- ⚠️ 대조 성립 조건 4가지(프롬프트 무변경 / structured output 강제 수준 / 재시도 정책 /
  `prompt_sha256`)를 **먼저 확인하고 결과를 적는다.** 여기서 갈리면 대조를 시작하지 않는다.
