## 1. 바뀌는 변수 — 하나

**"Researcher 검색에 에이전트가 고른 `tech_domain` strict 필터를 건다."**

- 항목(topic)마다 **선택 호출 1회**(json_schema, `enum` = 통제어휘 14개 + `"없음"`)를 한다.
  `"없음"`이면 `tech_domain=None`(= p1-on 경로와 같은 무필터 검색), 아니면 그 값으로
  `retrieval.search(query, k=4, tech_domain=…, trace=…)`(ADR-027 B, 전수 조회 후 strict).
- 그 뒤의 Researcher·Verifier·Writer 프롬프트·판정 로직은 **그대로**다.
- 도구 off이면 p1-on과 **입력 해시가 같아야 한다**(T2에서 테스트로 고정).
- ⚠️ 엄밀히는 두 가지가 함께 들어온다 — **(i) 선택 호출이라는 새 LLM 단계**와 **(ii) 필터**.
  (i)은 후속 노드의 입력을 바꾸지 않으므로(선택값만 검색 인자로 간다), 후속 노드 입력에서
  보이는 변화는 전부 (ii)를 거친 것이다. 이 전제가 깨지면(선택 응답이 다른 프롬프트에 섞이면)
  측정을 중단한다.

### 1.1 선택 시점 — **1회차 항목에서만 고르고 재시도는 그 값을 재사용한다** (확정, §6 D1)

- 선택 프롬프트의 입력은 (질의, 항목)뿐이라 재시도 회차에 다시 불러도 **입력이 같다.**
  다시 부르면 호출만 늘고, 비결정성이 있으면 같은 항목의 필터가 회차마다 바뀔 수 있다.
- 따라서 호출 증가분은 **1회차 항목 수**와 같다 — p1-on 기준 99건 / 30질의 = **질의당 +3.3**.
  (매 Researcher 호출마다 고르면 161건 = 질의당 +5.37이다. §5)

순위 순서를 유지하므로(ADR-027) 정답의 순위는 같거나 오른다.

## 3. 지표 정의

모든 지표는 **층별로 따로 내고 n을 병기한다**(ADR-022). 층 합산 지표는 만들지 않는다.
선택 단위 = **1회차 (케이스, 항목)** 쌍. 항목 = Outliner가 만든 topic 문자열.

### 3.1 정확 일치율 — 층 A (n = 14 케이스)

- **항목 일치:** 선택값 == 그 케이스의 오라클 값.
- **1차 표기 = 항목 풀링** (D2-d): `항목 일치 / 1회차 항목 수` (p1-on 기준 45개). 항목은 케이스 안에서
  상관이 있으므로(같은 질의) 이 수를 n=45의 독립 표본으로 해석하지 않는다.
- **관찰 병기:** 케이스 과반 일치 `k/14`.
- **판정에 쓰지 않는다** (D6-a). 오라클 값의 다수가 프로브 규칙의 산물이기 때문이다.

### 3.2 호환 일치율 — 층 A (판정 근거, D6)

- **항목 호환:** 선택값 ∈ 정답 문서의 `tech_domains`. 같은 형식(항목 풀링 + 케이스 과반 관찰)으로 보고한다.
- 호환 일치는 그 항목의 무해를 함의한다(§2). 판정 자체는 §3.4 해악으로 하고, 호환 일치율은 해악의
  원인(선택이 틀렸나 / 맞았는데 순위가 밀렸나 — 후자는 strict 정의상 불가)을 가르는 데 쓴다.

### 3.3 기권율 — 층 A·B·C 각각

- **기권:** 선택값 == `"없음"`. `기권 항목 / 1회차 항목`을 층별로 낸다.
- **선택 실패는 기권이 아니다.** 엔드포인트 오류(`LLMError`)로 선택값을 못 얻은 항목은
  `selection_error`로 따로 세고 무필터로 진행한다(p1-on 경로).
  **`selection_error` 항목은 모든 선택 지표(정확·호환 일치, 기권, 해악)의 분자·분모에서 제외**하고
  건수를 따로 보고한다. e2e pass/fail에는 그대로 포함된다(그 케이스는 표시한다).
- **스키마 위반은 기권도 실패도 아니다 — 실행을 멈춘다(§4).**

### 3.4 해악률 — 층 A·B 각각 (판정 1순위)

- **적격 항목:** 같은 검색어의 **무필터** top-4에 정답 문서가 있는 1회차 항목.
  p1-on 기준 층 A **36개(12케이스)**, 층 B **16개(6케이스)**.
- **해악 항목:** 적격 항목인데 **필터 후 top-4에 정답이 없다**(top-4 밖으로 밀림 또는 필터로 소멸).
- **이득 항목(기록용):** 무필터 top-4에 정답이 없는데 필터 후 top-4에 들어온 1회차 항목.
- **측정:** 무필터 대조는 LLM을 다시 부르지 않는다. T3 트레이스의 `search_text`를 무필터로
  재생한다(`replay_retrieval_trace.py`와 같은 방식, 검색은 결정적 — session-21 §5).
- 보고: `해악 항목 / 적격 항목` + **해악이 1건 이상 난 케이스 수 / 적격 케이스 수**.
- ⚠️ **층 B는 구조적으로 기권만이 무해하다.** 층 B 정답 문서(스냅샷 arXiv)는 온톨로지 메타가 없어
  strict 필터에서 **반드시** 탈락한다. 층 B에서 기권하지 않은 적격 항목 = 해악 항목이다.

### 3.5 e2e pass/fail — 층별 (bench `_score` 그대로, 판정 기준 무변경)

- p1-on 기준: **A 12/14 · B 5/9 · C 7/7.**
- **층 B는 절대 차이(건수)로 적는다** — `5/9 → x/9 (Δ = x − 5건)`. 비율·상대 변화로 적지 않는다
  (n=9에서 1건 = 11.1%p라 비율 표기가 차이를 부풀린다).
- 층 A·C도 건수와 뒤집힘 목록(pass→fail, fail→pass)을 함께 적는다.

### 3.6 negative(층 C)에서 기권이 정답인가 — **정답으로 채점하지 않는다** (확정, D5)

| | 근거 |
|---|---|
| **찬 (기권 = 정답)** | negative에는 정답 문서가 없다. 필터는 근거를 만들 수 없고 후보 풀만 바꾼다. 기권하면 p1-on 경로와 같아져 C 7/7이 그대로 보존된다. 필터 후 후보가 같은 도메인의 그럴듯한 문서로 채워지면 "근거 있음" 오판 위험이 오히려 생길 수 있다 |
| **반 (정답 아님)** | C의 질의는 대부분 **어휘 안의 주제**다 — GS-028(추론 서버 설정·처리량 → Inference/Serving), GS-009(GPU 비용 → Infra/MLOps), GS-026(파인튜닝 → Training/Finetuning). 선택 호출의 일은 "이 항목이 어느 도메인인가"이지 "코퍼스에 근거가 있는가"가 아니다. 근거 유무는 Researcher·Verifier의 일이다(ADR-006). 기권을 정답으로 채점하면 선택기에게 **코퍼스 커버리지를 맞히라**고 요구하게 되고, 선택기는 그것을 알 수 없다. 그리고 "없음"이 정답인 항목 라벨이 골든셋에 없다 |

- **결정(D5):** 층 C 기권율은 **기록만** 한다. 층 C의 판정은 e2e "근거 없음 유지"(7/7 대비 건수)로만 한다.
- 층 C e2e "근거 없음 유지"가 1건이라도 하락하면 해악이다(§6).

## 4. 정지 규칙 (판정 이전 — 위반 시 측정 무효)

## 7. n=14 해석 규칙

1. **건수로 먼저 적는다.** `k/14`가 1차 표기이고 %는 병기만 한다. 1건 = 7.1%p.
2. **유의성 검정을 하지 않는다.** 신뢰구간(Wilson 95%)은 참고로만 병기한다. 위 표에서 보듯
   12/14와 14/14의 구간이 겹친다 — n=14로는 1~2건 차이를 "모델이 잘한다/못한다"로 일반화할 수 없다.
3. **자연 변동은 0으로 관측됐다**(S0b run1↔run2, P1 off↔on: pass/fail 뒤집힘 0, 1회차 선택 차이 0).
   그래서 1건 차이는 **잡음이 아니라 실제 변화**로 보되, **"관찰"로만 기록**하고 판정은 ≥2건부터 한다
   (ADR-025 Amendment와 같은 하한). 시간 간 변동이 0이라는 근거는 없으므로 1건을 일반화하지 않는다.
4. **최난도 먼저, 평균 나중.** 해악은 케이스 상세(항목·선택값·무필터/필터 순위)를 먼저 적는다(ADR-005 Amd 2).
5. 층 합산 수치를 만들지 않는다. "30건 중 몇 건"은 쓰지 않는다(ADR-022).
6. 결론의 범위는 **현재 인덱스·코퍼스 37건·임베딩 핀·`gemma-4-31B-it`** 에 한정한다.

## 8. T2 소표본(3건)의 위치

- 경로 확인용이다(선택값·필터 후 결과 수·span 귀속 기록). **판정에 쓰지 않고, 위 임계값을
  소표본을 보고 바꾸지 않는다.** 바꾸려면 이 문서에 Amendment를 남기고 T3 전에 커밋한다.
